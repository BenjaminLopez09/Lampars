# Lúmina - Lámparas para Todos

## Descripción

Lúmina es una página web sencilla para una tienda ficticia
de lámparas de pie.

La página presenta diferentes productos, reseñas de clientes
y un formulario de contacto.

## Estructura del proyecto

El proyecto está compuesto por:

- `index.html` → Contiene la estructura y el contenido de la página.
- `styles.css` → Contiene todos los estilos visuales y el diseño responsivo.
- `README.md` → Explica brevemente el proyecto.

## Características

La página incluye:

- Estructura semántica HTML.
- Barra de navegación con enlaces internos.
- Sección de productos organizada con Flexbox.
- Cards individuales para cada producto.
- Sección de reseñas organizada con CSS Grid.
- Formulario de contacto mediante Formspree.
- Diseño responsivo mediante Media Queries.
- Google Fonts.
- Imágenes como contenido multimedia.
- Fondos con colores y degradados.
- Header y Footer personalizados.

## Formspree

Para activar el formulario de contacto es necesario crear
un formulario en Formspree y reemplazar en `index.html`:

`https://formspree.io/f/TU_ID`

por la dirección proporcionada por Formspree.

## Cómo modificar la página

Los textos de los productos, precios, reseñas y títulos
pueden modificarse directamente desde `index.html`.

Los colores, tamaños, espacios y diseño pueden modificarse
desde `styles.css`.

Las imágenes utilizadas en los productos también pueden
reemplazarse por imágenes propias.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Formspree
